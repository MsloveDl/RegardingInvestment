# MiniQMT知识库

## XtQuant文档

XtQuant是基于迅投MiniQMT衍生出来的一套完善的Python策略运行框架，对外以Python库的形式提供策略交易所需要的行情和交易相关的API接口。

本文件夹下的内容是MiniQMT知识库, XtQuant的文档.

文件说明如下:

* start.md -> 快速开始, 包括XtQuant能提供哪些服务, XtQuant运行依赖环境, XtQuant运行逻辑;
* xtdata.md -> XtQuant.XtData行情模块的说明;
* xttrader.md -> XtQuant.Xttrade交易模块的说明;
* complete-example.htm -> 完整示例, XtQuant的使用示例;
* frequently-asked-questions.htm -> 在使用中可能会遇到的一些问题;
