## 二、发现并修复的问题

### 2.1 严重问题（已修复）

#### 问题 1: main.py 导入错误
**位置**: main.py 第 9 行  
**问题**: `from utils import logger, trading_calendar, signal_bus, SignalType` 导入方式错误  
**影响**: 程序无法启动  
**修复**: 改为分别从各模块导入
```python
from utils.logger import logger
from utils.trading_calendar import trading_calendar
from utils.signal_bus import signal_bus, SignalType
```

#### 问题 2: data_adapter.py L2 数据字段映射不兼容
**位置**: data_adapter.py get_l2_quote_batch() 方法  
**问题**: 字段名硬编码为 `lastPrice`、`bidPrice1` 等，但 MiniQMT 可能使用不同命名  
**影响**: L2 数据获取失败，导致 SPP 和 MCP 无法工作  
**修复**: 添加多种字段名兼容处理
```python
'last_price': stock_data.get('lastPrice') or stock_data.get('last') or stock_data.get('price', 0)
```

#### 问题 3: risk_manager.py MA5 止损未实现
**位置**: risk_manager.py _is_below_ma5() 方法  
**问题**: 直接返回 False，止损逻辑失效  
**影响**: 无法执行动态止损，可能导致亏损扩大  
**修复**: 实现完整的 MA5 计算和判断逻辑

#### 问题 4: risk_manager.py 炸板监控未实现
**位置**: risk_manager.py _is_limit_up_broken() 方法  
**问题**: 直接返回 False，炸板卖出失效  
**影响**: 涨停炸板后无法及时卖出，可能导致利润回吐  
**修复**: 实现基于最高价和当前价的炸板检测逻辑

#### 问题 5: stock_monitor.py 板块协同检查未实现
**位置**: stock_monitor.py _check_sector_synergy() 方法  
**问题**: 直接返回 True，TS 因子失效  
**影响**: 无法过滤板块走弱时的个股，增加风险  
**修复**: 实现基于监控池内个股涨跌统计的板块协同检查

### 2.2 中等问题（已修复）

#### 问题 6: data_adapter.py 数据格式转换不完整

## 八、风险提示

### 8.1 技术风险

1. **数据延迟**：15 秒轮询可能错过急拉/急跌行情
2. **网络异常**：需要添加重试机制和降级策略
3. **API 变更**：MiniQMT API 可能更新，需要定期检查兼容性

### 8.2 策略风险

1. **市场环境**：策略适合情绪高涨的市场，震荡市/熊市效果可能不佳
2. **滑点成本**：实盘滑点可能高于预设的 0.5%
3. **流动性**：小盘股可能存在流动性不足问题

### 8.3 合规风险

1. **数据使用**：确保 L2 数据使用符合交易所规定
2. **交易频率**：避免被认定为高频交易
