## 三、数据接口变更

### 3.1 修改前（使用 L2 收费接口）

```python
# data_adapter.py
def get_l2_quote_batch(self, stocks):
    data = xtdata.get_l2_quote(stocks)  # ❌ 收费接口
    return {
        'bid_volumes': [...],  # 买一到买五量
        'ask_volumes': [...],  # 卖一到卖五量
    }

# stock_monitor.py - SPP 抛压探测
bid_total = sum(data['bid_volumes'][:5])
ask_total = sum(data['ask_volumes'][:5])
imbalance = bid_total / ask_total
if imbalance < 1.5:  # 买卖盘失衡
    剔除
```

### 3.2 修改后（使用免费接口）

```python
# data_adapter.py
def get_realtime_quote_batch(self, stocks):
    data = xtdata.get_full_tick(stocks)  # ✅ 免费接口
    return {
        'last_price': float,      # 最新价
        'volume': int,            # 成交量
        'change_rate': float,     # 涨跌幅
        'high': float,            # 最高价
        'low': float,             # 最低价
    }

# stock_monitor.py - SPP 抛压探测（降级版）
# 1. 涨跌幅检查
if change_rate < -2.0:  # 跌幅超过 2%
    剔除

# 2. 成交量检查
if volume < prev_volume * 0.5:  # 成交量萎缩
    剔除

# 3. 振幅检查
amplitude = (high - low) / pre_close * 100
if amplitude > 8.0:  # 振幅过大
    剔除
```

3. **数据延迟** ⚠️

   - **建议**：动态调整轮询频率（如 9:35-9:40 调至 10 秒）
