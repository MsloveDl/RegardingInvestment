## 📝 使用说明

### 快速启动

```bash
# 1. 安装依赖
pip install schedule xtquant

# 2. 配置参数
vim config.py  # 填写 MINIQMT_CONFIG

# 3. 运行策略
python3 main.py
```

### 配置说明

需要在 `config.py` 中配置：

```python
MINIQMT_CONFIG = {
    'account_id': '',     # 你的账户 ID
    'session_id': '',     # 你的会话 ID
    'data_path': '',      # 数据路径
}
```
