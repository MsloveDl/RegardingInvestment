### 3. 时间格式转换 ✅
**问题**: xtquant 需要完整日期时间格式  
**解决**: 在 `data_adapter.py` 中添加自动转换逻辑  
**代码**:
```python
if start_time and len(start_time) <= 8:  # 'HH:MM:SS' 格式
    from datetime import datetime
    today = datetime.now().strftime('%Y%m%d')
    start_time = f"{today} {start_time}"
```
