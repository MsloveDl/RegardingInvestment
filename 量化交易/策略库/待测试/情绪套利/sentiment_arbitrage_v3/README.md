# 情绪套利策略 v3.0 - 终极实战版

## 🎯 项目概述

情绪套利策略 v3.0 是一个基于市场情绪和板块协同性的量化交易系统，专注于在市场恐慌期识别具有反弹潜力的股票，通过快速进出实现套利收益。

### 核心创新

1. **SS (Sector Strength)** - 板块强度模型：实时计算板块动能
2. **SPP (Sell Pressure Probe)** - 抛压探测：量化个股卖压水平
3. **TS (Thematic Synergy)** - 题材协同性：分析板块内股票联动性
4. **MCP (Momentum Trigger Point)** - 动量触发点：精准把握入场时机

## 🚀 核心功能

### 1. 数据探针 (data_probe.py)
- **9:25集合竞价快照**：获取开盘前市场情绪数据
- **并发探针逻辑**：使用ThreadPoolExecutor实现高效数据采集
- **板块强度计算**：SS = (涨幅均值 × 涨停比例 × 量比均值) / 跌停比例
- **市场情绪判断**：基于跌停数量判断恐慌/乐观程度

### 2. 策略引擎 (strategy_v3.py)
- **综合评分模型**：Score = 0.3×SS + 0.25×(1-SPP) + 0.25×TS + 0.2×MCP
- **动态阈值调整**：根据市场波动性调整入场/出场条件
- **风险控制**：多层次止损和时间管理机制
- **T+1/T+2退出策略**：优化资金周转效率

### 3. 回测框架 (backtest_v3.py)
- **完整回测引擎**：支持历史数据回放和绩效分析
- **滚动退出逻辑**：模拟真实交易的时间约束
- **绩效指标计算**：夏普比率、最大回撤、胜率等关键指标
- **可视化报告**：生成详细的回测分析报告

### 4. 订单执行器 (executor_v3.py)
- **异步报单系统**：基于asyncio的高并发订单处理
- **模拟盘/实盘切换**：支持无缝切换交易模式
- **风险管理**：实时监控仓位和资金风险
- **订单状态跟踪**：完整的订单生命周期管理

## 🎯 核心算法

### SS (板块强度) 计算公式
```
SS = (板块平均涨幅 × 涨停比例 × 量比均值) / 跌停比例
```

### SPP (抛压探测) 计算公式  
```
SPP = ((大单卖出量 - 大单买入量) / 总成交量) × 价格波动率 × 100
```

### TS (题材协同性) 计算公式
```
TS = 同板块股票涨幅相关性 × 板块强度因子 × 领涨股因子
```

### MCP (动量触发点) 计算公式
```
MCP = 短期动量 × 成交量动量 × 价格突破因子
```
