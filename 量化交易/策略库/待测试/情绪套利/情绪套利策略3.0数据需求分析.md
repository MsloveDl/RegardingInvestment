## 策略因子与数据依赖

### 3.1 板块强度 SS

```
SS = W1 * SR + W2 * OR + W3 * CR

- SR (涨停共振因子): 竞价涨幅 > 9.5% 的个股数量 → ✅ 免费 tick 数据
- OR (封单强度比): 封单金额 / 板块流通市值 → ✅ 免费 tick 数据
- CR (抗撤单因子): 1 - (撤单金额 / 总封单金额) → 💰 需要 Level2
```

**CR 因子需要 Level2**，否则无法获取撤单数据。

### 3.2 抛压探测 SPP

```
SPP 剔除条件：
1. 开盘跌幅 > 3% → ✅ 免费
2. 买卖盘失衡比 < 1.5 → ⚠️ 免费可用但精度低
3. 大单净流出 > 5日均值*2 → 💰 需要 Level2
4. 距套牢区 < 3% → ✅ 免费（自行计算）
```

**条件3需要 Level2** 获取逐笔成交判断大单。

### 3.3 题材协同性 TS

```
TS(t) = 板块内上涨个股数 / 板块总个股数
```

**✅ 免费数据即可实现**

### 3.4 动量确认点 MCP

```
MCP 触发条件：
1. 价格 > 前5分钟最高价 → ✅ 免费
2. 成交量 > 前5分钟均量*150% → ✅ 免费
3. SPP = False → ⚠️ 部分依赖 Level2
```

## 结论

### 完整实现策略 v3.0

| 需求 | 说明 |
|------|------|
| **Level2 权限** | ⚠️ **必须** |
| 关键依赖 | CR 抗撤单因子、大单流向判断 |

### 降级方案（仅用免费数据）

如果没有 Level2 权限，可以做以下调整：

1. **CR 因子** → 放弃或改用替代指标：
   - 替代方案：`竞价成交额 / 封单金额` 的比值
   - 逻辑：成交额越接近封单额，说明撤单越少

2. **大单流向** → 改用成交量异常检测：
   - 替代方案：`当前分钟成交量 / 5日同时段均量`
   - 逻辑：放量可能意味着大单活跃

3. **买卖盘失衡** → 使用普通 tick 五档数据：
   - 限制：更新频率 3 秒一次，非逐笔
   - 可接受：对于分钟级策略影响不大

4. **实时监控频率** → 降低到 3 秒级：
   - 普通 tick 数据更新频率限制
   - 策略时间窗口 9:30-9:45，影响可控

### 降级版可行性评估

| 维度 | 完整版 | 降级版 |
|------|--------|--------|
| 信号精度 | 高 | 中 |
| 撤单识别 | ✅ 精确 | ❌ 无法识别 |
| 大单判断 | ✅ 精确 | ⚠️ 近似估算 |
| 实时性 | 逐笔级 | 3秒级 |
| 可用性 | 💰 付费 | ✅ 免费 |
