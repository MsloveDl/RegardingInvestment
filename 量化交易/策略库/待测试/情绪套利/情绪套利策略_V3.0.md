# 《情绪套利策略 v3.0 - 终极实战版》策略规格说明书 (Specification)

## 1. 策略定位 (Strategic Positioning)

本策略是 **Final_Sentiment_Arbitrage_Strategy** 与 **Qingyun_Quant_Analysis** 的深度基因融合产物。它保留了“情绪溢出套利”的竞价共振与筛选框架，同时深度整合了青云量化系统的 **AI动态感知、盘中确认、抛压探测与T+1/T+2滚动交易** 核心哲学。

**核心理念**：**不预测，只跟随**。利用 9:30 的实时数据作为“全市场探针”，在强情绪板块中，精确捕捉抛压最小、动量最强的补涨个股，实现高周转、低回撤的超短线套利。

---

## 2. 核心逻辑总结：全市场探针式扫描 (9:30)

策略的核心是利用开盘后15分钟（9:30 - 9:45）的市场“初态”数据进行实时决策，而非依赖预判。整个系统如同一张覆盖全市场的“神经探针网”：

1.  **环境感知 (9:25前)**：判断今日是否为“可交易日”。（全局开关）
2.  **板块雷达扫描 (9:25)**：锁定竞价阶段情绪最强、共振最明显的1-3个热点板块。（缩小战场）
3.  **个股探针激活 (9:30-9:45)**：在目标板块内，对每只符合条件的个股启动“动态探针”，实时监控其：
    *   **抛压信号**（卖盘挂单深度、大单流向）。
    *   **动量信号**（价格突破、量比放大）。
    *   **协同信号**（与板块整体走势的同步性）。
4.  **信号合成与触发**：当单个个股的探针信号综合评分超过阈值，且板块环境依然健康时，系统自动下达买入指令。

**整个过程是动态、并行、条件触发的，完美融合了两种策略的优点。**

## 3. 因子量化定义 (Quantitative Factor Definitions)

所有因子必须可被量化，并在回测和实盘中精确计算。

### 3.1 板块强度 (Sector Strength) - `SS`
用于在9:25筛选出全天可能最强的板块。
```
SS = W1 * SR + W2 * OR + W3 * CR

其中：
- SR (涨停共振因子) = 板块内竞价涨幅 > 9.5% 的个股数量。 (N_lu)
- OR (封单强度比) = (板块内涨停股总封单金额) / (板块流通总市值)。该值需进行全市场排名，取排名分位数。
- CR (抗撤单因子) = 1 - (板块在9:19至9:25的总撤单金额 / 9:19总封单金额)。用于过滤“诱多”。
- W1, W2, W3 为权重，建议 [0.4, 0.4, 0.2]。

筛选条件：SS 排名全市场前三，且 SR >= 3, CR > 0.5。
```

### 3.2 抛压探测 (Selling Pressure Probe) - `SPP`
用于在9:30后剔除板块内的“弱势雷股”和“抛压沉重股”。
```
SPP = 综合以下布尔条件，任一为True则标记为高抛压，剔除：
1. 开盘跌幅 > 3%。
2. 买卖盘挂单失衡比 (Bid_Ask_Imbalance) = (买一至买五总量) / (卖一至卖五总量) < 1.5。
3. 开盘后第一分钟大单净流出金额 > 过去5日同时段平均值的2倍。
4. 现价距离上方最近一个筹码密集套牢区 (如250日成本均线) < 3%。
```

### 3.3 题材协同性 (Thematic Synergy) - `TS`
用于在盘中确认板块热度是否持续，防止买入“板块内独立下跌股”。
```
TS(t) = 板块内上涨个股数量 / 板块内总个股数量

动态监控条件：
- 买入时刻，TS(t) 必须 >= 70%。
- 监控窗口：从9:30至计划买入时刻，TS(t) 从未跌破60%。
```

### 3.4 个股动量确认点 (Momentum Confirmation Point) - `MCP`
最终的买入触发信号。
```
MCP 触发条件 (需同时满足)：
1.  实时价格 > 开盘后前5分钟（9:30:00 - 9:35:00）的最高价。
2.  触发时的成交量 > 开盘后前5分钟的平均每分钟成交量的150%。
3.  触发时，该个股的 SPP = False (即无高抛压信号)。
```

## 5. 风控与退出机制 (Risk & Exit)

### 5.1 持仓退出规则 (T+1/T+2 滚动止盈止损)

| 情景 | 退出规则 | 执行时间 |
| :--- | :--- | :--- |
| **常规止盈** | T+1 日，**9:25:00 集合竞价**全仓卖出。 | T+1日 9:25:00 |
| **涨停持有** | 若T+1日竞价结束封死涨停（涨幅>=9.8%），则持有至T+2日竞价。 | T+1日 9:25后 |
| **炸板卖出** | 若T+1日盘中涨停后开板（炸板），**开板瞬间立即卖出**。 | T+1日盘中 |
| **动态止损** | **买入当日（T日）**，若收盘价跌破 **5日移动平均线** 或 **当日分时均线**，则次日竞价无条件卖出。 | T日收盘判断，T+1日执行 |
| **时间止损** | 无论盈亏，持仓最长不超过 **T+3** 个交易日。 | T+3日 9:25 |

### 5.2 全局熔断与账户风控

1.  **日内账户熔断**：当日所有持仓的 **总浮动亏损** 达到总资产的 **3%** 时，立即停止所有新的买入信号探测，且仅允许卖出操作。
2.  **板块熔断**：`龙头炸板保护`。若板块内识别出的“龙一”个股在10:00前涨停开板且5分钟内未回封，该板块即刻移出“目标板块”列表，并停止对该板块内所有个股的监控与买入。
3.  **滑点控制**：在回测与实盘下单时，预设 **单边0.5%** 的滑点成本。
4.  **仓位管理**：
    *   单只个股仓位：总资产的 **5%**。
    *   单日最大开仓个股数：**3只**。
    *   单一板块最大暴露仓位：总资产的 **15%**。

## 6. 代码实现要点 (Implementation Notes for Workstation)

1.  **数据结构**：需维护`板块强度表`、`个股监控池`、`实时探针状态字典`。
2.  **并发处理**：使用 `asyncio` 或 `multiprocessing` 模拟“分布式探针”，同时对数百只个股进行 `SPP` 和 `MCP` 的实时计算。
3.  **数据源依赖**：
    *   9:25的快照数据（含封单）用于计算 `SS`。
    *   实时L2 Tick数据（买卖五档、成交明细）用于计算 `SPP` 和 `MCP`。
4.  **信号总线**：建立一个中央信号总线，汇总所有探针的结果，由主逻辑进行最终的买入决策与风控判断。
5.  **状态持久化**：交易日历、持仓状态、熔断状态需要持久化存储，以应对程序重启。

## 7. 回测与优化方向 (Backtest & Optimization)

1.  **核心参数**：`SS`因子权重 (`W1, W2, W3`)、`MCP`触发所需的量比阈值、`SPP`中各子条件的阈值。
2.  **回测重点**：
    *   **胜率与盈亏比**：重点评估T+1竞价卖出的总体胜率与平均盈亏比。
    *   **最大回撤**：验证在 **全局熔断** 和 **账户熔断** 规则下的回撤控制效果。
    *   **市场环境适应性**：在不同市场风格（牛市、震荡市、熊市）下的表现。
3.  **实盘过渡**：回测通过后，需进行 **小资金实盘模拟**（如1万元），重点验证下单速度、滑点真实情况与系统稳定性。
