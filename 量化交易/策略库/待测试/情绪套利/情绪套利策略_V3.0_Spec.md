# 情绪套利策略 v3.0 - 终极实战版 (Spec v3.0) 🎧🖤

## 1. 核心哲学
本策略不预测市场，只跟随 **“钱的声音”**。通过 9:25 的竞价数据捕捉市场最强的“情绪共振点”，并利用 9:30-9:45 的动态窗口进行抛压过滤，通过 T+1 的极速滚动实现复利。

## 2. 因子量化定义

### A. 全场环境因子 (Environment Switch)
- **踩踏滤网**: 9:25 分跌停个股数 $\le 5$。
- **趋势保护**: 沪深 300 指数运行在 20 日均线之上。
- **赚钱效应**: 过去 3 日首板成功率 $> 40\%$。

### B. 板块强度因子 (Sector Strength)
- **共振计数**: 申万二级板块内，竞价涨幅 $> 9\%$ 的个股数 $\ge 3$。
- **资金密度**: 板块内涨停股封单总金额 / 板块总流通市值 $\rightarrow$ 全市场排名 Top 3。

### C. 个股情绪因子 (Individual Score)
- **开盘溢价**: $+2\% \le \text{开盘涨幅} \le +5\%$。
- **量比突变**: 竞价成交额 / 5日平均成交额 $> 10\%$。
- **抛压探测**: (买五总单量 / 卖五总单量) $> 2$。

## 3. 精准执行指令

| 时间段 | 动作 | 目标 |
| :--- | :--- | :--- |
| **09:25:00** | 全市场 Snapshot | 锁定板块热度与竞价数据 |
| **09:26-09:29** | 探针扫描 | 计算板块强度，生成候选池 (Top 5) |
| **09:30:00** | 开盘监控 | 排除跌幅 $> 3\%$ 的弱势股 |
| **09:35-09:45** | 动态买入 | 股价突破 09:30-09:35 的高点时介入 |

## 4. 退出与风控 (T+1/T+2)
- **标准退出**: T+1 日 9:25 集合竞价直接以市价单卖出（无论盈亏）。
- **连板锁定**: 若 T+1 日竞价封死涨停，持股观察。开板瞬间秒卖。
- **单日熔断**: 账户当日总价值回撤 $> 3\%$，停止所有新买入。
