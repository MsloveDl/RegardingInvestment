# 青云量化系统 (Qingyun Quant) 深度分析报告

## 1. 核心逻辑：AI 驱动的动态情绪捕捉
与我们之前的“静态竞价套利”不同，该系统更强调**盘中动态捕捉**和**多维度因子探测**。

- **交易频率**: 超短线 (T+1/T+2)。
- **核心逻辑**: 并非简单的抢涨停，而是利用 AI 探测“抛压”与“动量”的平衡点。
- **核心特色**: 强调“不预测，只跟随实时数据”。

## 2. 关键入场因子与逻辑差异

| 维度 | 我们之前的策略 | 青云量化系统 | 启示 |
| :--- | :--- | :--- | :--- |
| **执行时间** | 锁定 9:30:00 一次性下单 | 9:30 - 9:59 动态触发 | 增加了盘中确认过程，可过滤“假高开” |
| **筛选条件** | 涨幅 +2% ~ +5% | 排除开盘跌幅 > 3% | 证明了“弱势个股”即使在强板块也是雷 |
| **数据源** | QMT 官方快照行情 | 分布式探针 (多服务器探测) | 极致的数据处理速度，防止数据拥堵 |
| **共振确认** | 竞价封单量 | 题材集体上涨协同性 | 盘中需持续监控板块内个股的上涨比例 |

## 3. 值得吸收的“黑科技”因子

1. **抛压探测 (Selling Pressure Probe)**: 
   - 寻找高位缩量调整的标的，避开抛压沉重的股票。在量化中，这可以通过监控“卖盘挂单深度”和“大单成交比”来实现。
2. **信号分级系统**: 
   - 他的系统有强度条。我们可以在代码中加入“信心指数”，例如：大盘环境、板块共振、个股强度各占权重，总分越高仓位越重。
3. **防御+反击模式**: 
   - 市场行情不好时自动收缩（学会不买）。这印证了我们“大盘滤网”的重要性。

## 4. 如何在 MiniQMT 中实现类似功能？

- **分布式思路**: 虽然我们没有多台服务器，但可以用 Python 的 `multiprocessing` 或 `asyncio` 在本地模拟“并发探针”，同时监控几百只票的 L2 抛压数据。
- **动态确认逻辑**: 将买入代码从 9:30 准时触发，改为 9:30 - 9:40 间的“突破买入”或“回踩买入”。
