# 人间正道是沧桑

> URL: https://xueqiu.com/4327270746/356157944

来源：雪球App，作者： 为霜，（https://xueqiu.com/4327270746/356157944）
今晚回家，打开热门看了一下，发现60条热门有一大半都在讨论昨晚川无能狂怒的咆哮对我们周一的影响。
让我意外的是，看了热门贴下面茫茫多的回帖，居然还有这么多人认为我们要完.....我真是醉了。
生物多样性在雪球真是表现得淋漓尽致。
其实我现在都没什么发言的欲望，但是实在太过无聊，刷帖子又没啥看的。只是自己给自己灌水打发时间。
当然，让我发言更重要的原因是，我认为这一刻是中华民族又一次的历史转折点，我必须要用自己的笔墨记录下这光辉的一刻。
论权谋，在这个蓝色星球，我们如果认了第一，都没有人敢认第二。为什么？因为我们是断层领先的唯一。能跟我们比权谋的，恕我眼拙，目前一个也没有。
鲁迅先生曾经在《狂人日记》中写到：“我翻开历史一查，这历史没有年代，歪歪斜斜的每页上都写着‘仁义道德’几个字。我横竖睡不着，仔细看了半夜，才从字缝里看出字来，满本都写着两个字是‘吃人’！”
论“吃人”，我们已经吃了3000多年，而美国，才在去年由国务卿安东尼·布林肯领会到这层含义：“在国际体系中，如果你不坐在餐桌上，你就会出现在菜单上”。而我们已经领先了3000多年......
在2018年，当时川普第一任的时候，突然提出要脱钩加关税与科技封锁，那个时候，我们的确是很被动，也的确没有什么办法。最大的短板就是在芯片半导体上。然而，7年过去了，我们早已今非昔比，更重要的是，七年前的警钟让我们惊醒。其实在七年前，我们已经在默默为今天做准备了。
而在今年4月，当川普再次重施故技，老调重弹的时候，其实，我们已经底气十足了。那时候为什么不掀桌子呢？因为我们“稳”。
我们3000年的治国精髓，其实就是一个“稳”字。治大国若烹小鲜。而其实在当时，我们已经默默准备好了一套组合拳。
第一步，先统一战线，对内对外都在做政治舆论宣传：我们支持全球化，我们热爱和平，拥抱发展，共建人类命运共同体。但，我们也不畏战，不惧战，谈，我们欢迎，打，我们奉陪。坚持合作共赢，平等发展。这第一波就是舆论宣传战，先让自己站在道德的制高点，为未来出师有名，名正言顺。
第二步，团结一切可以团结的力量。无论是北方的俄罗斯，西亚的伊朗阿拉伯，还是东南亚各国，还是非洲兄弟，还是巴西委内瑞拉的中南美洲各国，甚至包括欧盟内部的匈牙利，塞尔维亚，甚至法国左派，德国右派，等等等等。得道者多助，失道者寡助。其实，当众多第三世界的国家与人民团结在我们身边的时候，胜利的天平就已经开始倾斜了。
第三步，开始秀肌肉。我们并不是好战的民族，我们热爱和平，渴望发展，希望能够带领全世界人民走向幸福生活。这是我们在100多年前在建党的时候，就已经明确写入党章的纲要。所以，我们开始9,3阅兵。开始向全世界展现我们的黑科技，我们断层的军工领先优势。
直到这个时候，美国战争部开始沉默了，居然在全世界召回军官，召开了全军动员大会，要求有勇敢与牺牲精神去投入新的挑战.....如果不是看新闻，我差点以为是我们在喊口号。
第四步，开始反击了。先是召见英伟达，说你们的芯片有后门。再是宣布高通违反反垄断法。无论英伟达还是高通，以前都是我们的命根子。而现在说禁用就禁用，说罚款就罚款。这说明了什么？答案再明显不过了。
第五步，宣布开始我们的稀土长臂管辖。这已经不是在防御了，而是直接赤裸裸的上去扇嘴巴了。所以，昨晚对面才会如此无能狂怒。
如果看到这里你还不明白，如果这个时候你还要跪，就已经不是气节与风骨的问题了，而是脑子的问题了。
我认为，这就是中华民族历史上一个伟大的转折点，她的意义能够比肩朝鲜战争的伟大胜利。
近代100多年的屈辱，近代无数革命先烈，科学先驱，有识之士的流血牺牲，眼泪与屈辱，由辛亥革命，到抗日战争，到解放战争，到朝鲜战争；从改革开放，到韬光养晦，在到今天狠狠的删对手的耳光。整整100多年了，是无数中华儿女奋斗牺牲的历史凝聚的今天！今天，我们不仅站起来了，而且是又一次历经风雨磨难后，再次站回了民族之巅。中华民族，王者归来！
到了这里，其实一切都是明牌了，我们之前没有翻桌子，并不是我们没有翻桌子的能力，而是我们求稳，能够隐忍，我们还在计算；而今天，我们翻桌子了，不翻则以，翻，就意味着我们已经有了掌控一切的能力与从容。因为，我们过去3000多年的历史就是这样过来的。只要是翻桌子，就基本意味着大局已定，一切尽在掌握。治大国若烹小鲜，既然敢翻小鲜，就意味着火候已经到了。
所以，问我周一怎么走，我说，你眼光窄了，眼界低了。周一怎么走重要吗？我们已经走在了一条中国科技爆发，中国资产重定价，岁将大计，万国来朝的长期牛市道路中了。
这时候，请允许我用主席的一首诗七律作为结尾：
钟山风雨起苍黄，百万雄师过大江。
虎踞龙盘今胜昔，天翻地覆慨而慷。
宜将剩勇追穷寇，不可沽名学霸王。
天若有情天亦老，人间正道是沧桑。
